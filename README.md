# Customer Churn Prediction

Bu proje, bir telekomünikasyon şirketinin hangi müşterilerinin hizmetten ayrılma eğiliminde olduğunu makine öğrenmesi ile tahmin etmeyi amaçlayan bir Data Science / Machine Learning bootcamp final çalışmasıdır.

Customer Churn (müşteri kaybı), bir müşterinin şirketin hizmetini kullanmayı bırakmasıdır. Projede müşteri özellikleri ve hizmet bilgileri kullanılarak `Churn` hedef değişkeninin tahmin edilmesi ele alınacaktır.

## Veri Seti

[IBM Telco Customer Churn](https://github.com/IBM/telco-customer-churn-on-icp4d/blob/d5371f5d83a446ad5673cbcca3b814b926491f8a/data/Telco-Customer-Churn.csv) veri seti kullanılmaktadır. Veri seti, IBM'in yayımladığı kurgusal bir telekomünikasyon şirketine ait müşteri bilgilerini içerir.

## Temel Teknolojiler

- Python
- pandas ve NumPy
- Matplotlib ve Seaborn
- scikit-learn
- Jupyter Notebook
